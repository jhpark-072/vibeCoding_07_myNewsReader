# 맞춤형 뉴스 리더 (Custom News Reader)

순수 HTML5, CSS3, Vanilla JavaScript(ES6+)로 제작된 **맞춤형 뉴스 리더 웹 애플리케이션**입니다. 별도의 빌드 도구나 라이브러리 설치 없이 브라우저에서 바로 실행할 수 있습니다.

---

## 🌟 주요 기능 및 요구사항 구현 내용

1. **주제 다중 선택 목록 & '뉴스 보기' 버튼**
   - **비즈니스**, **스포츠**, **문화** 3가지 카테고리를 복수 선택 가능한 반응형 칩(Chip) 버튼으로 제공합니다.
   - 주제를 1개 이상 선택하면 '뉴스 보기' 버튼이 활성화되며, 현재 선택된 주제 상태를 실시간으로 요약 안내합니다.

2. **Open API 연동 및 주제별 상위 10개 피드 추가**
   - 무료 실시간 뉴스 Open API (`ok.surf CORS News Feed API`)를 통해 각 주제별 최신 기사를 수신합니다.
   - '뉴스 보기' 클릭 시 선택된 각 주제에서 **상위 10건씩** 기사를 가져와 피드에 즉시 추가합니다. (예: 3개 모두 선택 시 30건 표시)

3. **기사 카드 및 본문 상세 모달 (Modal)**
   - 각 카드는 **제목**, **대표 썸네일 이미지**, **언론사/발행일자**, **카테고리 뱃지**, **'읽기' 버튼**으로 구성됩니다.
   - '읽기' 버튼 클릭 시 배경 딤(Dim) 처리와 함께 **상세 모달**이 열리며, 본문 내용 및 원문 언론사 바로가기 링크를 제공합니다.
   - `ESC` 키 입력, 닫기 버튼, 또는 배경 클릭으로 모달을 손쉽게 닫을 수 있습니다.

4. **무한 스크롤 (Infinite Scroll - 10건씩 추가 로딩)**
   - 브라우저 표준 `IntersectionObserver API`를 적용하여 페이지 하단 감지 영역(Sentinel)에 도달하면 자동으로 **기사 10건을 추가로 불러옵니다.**
   - 로딩 스피너 및 모든 기사 수신 완료 안내 메시지가 제공됩니다.

5. **깔끔한 카드 디자인 & 반응형 그리드 레이아웃**
   - 카드에 순백색(`#ffffff`) 배경과 은은하고 부드러운 드롭 섀도우(`box-shadow`) 및 호버 시 자연스러운 입체 효과를 적용했습니다.
   - CSS Grid 기반 반응형 디자인:
     - **모바일 (< 640px):** 1열 그리드
     - **태블릿 (640px ~ 1024px):** 2열 그리드
     - **데스크톱 (≥ 1024px):** 3열 그리드

## 🚀 실행 방법

### 방법 1: 브라우저에서 바로 실행
- 폴더 내 `index.html` 파일을 더블 클릭하여 Chrome, Edge, Safari 등의 웹 브라우저에서 바로 열 수 있습니다.

### 방법 2: 로컬 웹 서버 실행 (권장)
VS Code Live Server 확장 프로그램을 이용하거나, 터미널에서 다음 명령어를 실행할 수 있습니다:

```bash
# Python 내장 웹 서버 실행 예시 (포트 8000)
python -m http.server 8000
```
그 후 브라우저에서 `http://localhost:8000`으로 접속하시면 됩니다.
